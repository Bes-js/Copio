# Copio 1.2.0

## A polished install experience

Copio now opens from a purpose-built installation window. Drag Copio to Applications to install it, with a clean visual guide that matches the app's icon and dark macOS style.

## Included

- Refined DMG installer with a branded background and clear drag-and-drop guidance
- Universal build for Apple Silicon and Intel Macs
- ZIP download alternative and SHA-256 checksums for download verification
- Sparkle-signed DMG update feed for secure in-app updates

## Requirements

- macOS 14 Sonoma or later
- Apple Silicon or Intel Mac

## First launch

Copio is distributed without Apple notarization. If macOS blocks its first launch, open **System Settings → Privacy & Security** and select **Open Anyway** after confirming you trust the download.
